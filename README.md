## Featured Work

**[ORCA](https://griffinslelgut.vercel.app/projects)** — AI Agent Guardrail System (LTTS Hackathon)
- Policy Gate: a deterministic rule engine that screens every AI-agent action before execution (denylist, prompt-injection guard, least-privilege allowlist, human-approval interlock).
- Governance Gate: a task agent reports confidence while a judge agent independently reviews output; disagreement freezes the run.

**[Noteleaf](https://github.com/Griffins2005/noteleaf)** — Ambient AI Meeting Notetaker
- On-device speech transcription via the browser Web Speech API; sentences classified into actions, decisions, or insights in under 1 second, with NVIDIA Nemotron recaps.
- 18-endpoint Fastify REST API with httpOnly-cookie JWT auth, rotating refresh tokens, and a 4-service Docker Compose stack.

**[Nestopia](https://github.com/Griffins2005/Nestopia)** — Rental Matching Platform
- Preference-weighted compatibility scores between renters and properties, with listing, auth, and landlord–renter workflows.
- FastAPI + PostgreSQL backend and React frontend; live at [nestopia-rental.vercel.app](https://nestopia-rental.vercel.app).

**[CF AI API Copilot](https://github.com/Griffins2005/cf-ai-api-copilot)** — Cloudflare Workers Assistant
- Ingests OpenAPI/Swagger specs, persists digests and chat history in Durable Objects, and answers multi-turn API questions with Workers AI.
- Auto-generates cURL and fetch snippets for every documented endpoint; runs on Cloudflare’s edge.
